# Markdown Studio Pro for macOS

Native macOS shell for Markdown Studio Pro.

## Build in Xcode

1. Open `MarkdownStudioProMac.xcodeproj`.
2. Select the `MarkdownStudioProMac` scheme.
3. Build with `Cmd+B`.
4. Run with `Cmd+R`.

## Included

- native macOS app
- SwiftUI shell around a `WKWebView`
- native toolbar and menu bar
- document open, save, and save as
- common text-file opening support
- light, dark, and system appearance
- HTML export

## Notes

- The HTML/JS editor is bundled and loaded from `MarkdownStudioProMac/App/editor.html`.
- Xcode handles local signing during development.
- The Windows app is not included yet.
